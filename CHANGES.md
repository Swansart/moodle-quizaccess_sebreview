# Changes

## 1.0.0 (2026-11-11)

- First release.
- New quiz setting "Require Safe Exam Browser for review".
- The review of attempts and the single-question review are only shown in a Safe Exam
  Browser that passes the check of the standard Safe Exam Browser access rule.
- The web service used by the Moodle app does not return the review of such quizzes.
- Support for backup, restore and duplication of quizzes.
- Tested on Moodle 4.4, 4.5, 5.0, 5.1, 5.2 and 5.3.
